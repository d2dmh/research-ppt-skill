# 按评审意见重排页面（低成本的“逐页改版”做法）

## 什么时候用

用户或评审方（网页端 GPT）看过渲染稿，要求「这几页改成另一种版式」。
**不要**改大 build 脚本再全量重跑，**也不要**逐页手改 PPTX——都会在下一轮重跑时丢掉。

## 做法：补丁脚本

1. 大 build 脚本（如 `build_v2.py`）照旧生成 `content-vN.json`。
2. 写一个小脚本 `patch_slides.py`：读 `content-vN.json` → 按**页索引**替换指定页的整段 dict → 写 `content-v(N+1).json`。
3. 用补丁后的 JSON 生成 PPTX。顺序固定：**build → patch → dense_deck**。
   好处：重跑 build 不覆盖补丁，每页新版式在补丁脚本里一眼可读、可反复调参。
4. 补丁脚本里顺手做**全局后处理**，比逐页改省事：
   - 不许用红的页面上 `highlights` / `emphasis` 全部剥掉（用 `ALLOW_RED = {2, 6, 10, 24}` 这类白名单）；
   - 表格一律 `pop('emphasis')`；
   - **高亮词做子串校验**：不在正文里的 highlight 丢弃并告警——否则静默失效（见 SKILL.md 红色那节）。

## 用 `layout: full` + 自定义 `box` 搭任意版式骨架

`full` 下 `main` 默认 [0.5, 1.5, 12.5, 5.06]；给 region 传 `box` 就能自由分区：

| 骨架 | 分区 |
|---|---|
| 左右对比（无灰底） | 左 [0.5,1.5,6.15,h] + 右 [6.85,1.5,6.15,h] + 底部一句 [0.5,≈4.9,12.5,0.6]，`fill:"none"` |
| 图占 72% 的图文页 | `main` 显式 `box:[0.5,1.5,8.85,5.06]` + 侧栏 [9.55,1.5,3.45,≈3.9] |
| 三路线 + 全宽命令区 | 三个 [x,1.5,4.0,1.8] + 命令区 [0.5,3.75,12.5,2.0]（`fill:"gray"`） |
| 四节点责任链 | `flow` 一行四个标签 + 四条编号正文（不要用表） |
| 五步横向流程 | `flow(style:"box")` 一行五步 + 五条说明 + 一条“失败退回上一步” |
| 素材/录屏页（图必须大） | `main` box=[0.5,1.5,8.6,4.85] 放 `figure`（h=4.85，约占半页）+ 侧栏 [9.3,1.5,3.7,4.85] 放 3–4 条“看什么” |
| 图 + 解释文字（分享人认可度最高的组合） | 左/图占主体，右/窄栏写“看这张图看什么”，页底结论条只留一句判断 |

## 目录重复出现与删页重排（脚本片段）

参考稿的目录页在每个部分开头各出现一次（P2/P5/P8/P17/P27），数据用 `active` 高亮当前部分：

```python
import copy
_toc = S[1]                                   # 第 2 页就是 {"type":"agenda","active":0,"items":[5 项]}
for _i, _sec in enumerate(["02", "03", "04", "05"], start=1):
    _pos = next(i for i, x in enumerate(S) if x.get("section") == _sec)   # 每轮重算，插入不算老位置
    _a = copy.deepcopy(_toc); _a["active"] = _i
    S.insert(_pos, _a)
```

删页 / 合并页之后**必须重排小节编号**（否则断号），按 `section` 分组重编，注意 `section` 是 "01" 字符串、
`int()` 去前导零，否则拼出 `01.1`：

```python
del S[10]      # 先删索引大的，再删小的，避免错位
del S[6]
import re
_cnt = {}
for _sl in S:
    _m = re.match(r"^(\d+)\.(\d+)\s+(.*)$", _sl.get("title") or "")
    if _m and _sl.get("section"):
        _cnt[_sl["section"]] = _cnt.get(_sl["section"], 0) + 1
        _sl["title"] = "%d.%d %s" % (int(_sl["section"]), _cnt[_sl["section"]], _m.group(3))
```

删完 grep 全稿确认没有对已删页的引用（“2.7 ”“智能体不等于完全自动化”这类关键词为零）。
| 无表头的对照页 | 两列各 [6.15] 宽，每列内部用“短标题\n一句话”的正文条目代替表格 |

**硬坑**：`full` 里加了自定义侧栏却**没给 `main` 写 `box`** 时，图按整幅宽居中（约 8.99 英寸），
直接压到侧栏区域上——**生成日志不会报重叠**，只有看渲染图才能发现。

## 分区高度怎么定

- 生成日志 `region 'x' has N in empty (M%)`：M > 25% 就收紧 `box` 高度，或补有信息量的事实。
- `over-full`：加高 `box` 或删条目；命令类长行可降到 11–12pt（代码/命令不属于“正文 16pt 下限”的范围）。
- **先按内容量定高度，再谈美观**；反过来会一直来回改。

## 页级检查顺序（每轮重排后）

1. `dense_deck.py` 的日志：`over-full` / `in empty` 归零；
2. `lint.py`：错误级归零（注意拉丁文本假阳性，见 SKILL.md）；
3. `render.py` → 拼一张**只含本轮改动页**的对照表发出来看：
   空面板、图是否被压小、红字是否只在关键判断上、留白是否过多——一次看 4–8 页最有效。
