# 原稿排版规则：颜色角色、字号、品牌与信息密度

本规则以原31页答辩稿的实际页面结构为依据，并采用用户明确要求的蓝、黑、红三色正文体系。26页密度样例在 `assets/density-demo.json`，通过原生对象验证这些结构；它使用合成示意数据，不是实证研究报告。

## 1. 三色按信息角色使用

| 文字角色 | 颜色 | 规则 |
|---|---|---|
| 章节、结构标题、模型名、图组名 | #1D50A2 蓝 | 建立层级与图文对应关系 |
| 正文、定义、公式解释、表格内容、图注 | #000000 黑 | 承担主要论证，不用灰字模拟层级 |
| 研究缺口、关键变量、条件、判断、定位标注 | #C00000 红 | 在黑色段落内局部强调，通常每段1–3处 |

白色只用于蓝色底上的目录文字、章节编号、表头与页码，不算正文中的第四个强调色。内容分区统一用灰底 #F2F2F2，只有页底结论条用浅橙 #FCEBDD；数据图系列可用区分性颜色，但图例/坐标文字遵守三色文字体系。不要把整页结论或说明一律染红。

## 2. 恢复原稿的视觉体量

| 元素 | 当前基线 | 不合格表现 |
|---|---|---|
| 封面题目 | 40pt；较长时36–40pt或主动分两行 | 主标题缩成内容页小标题 |
| 封面署名 | 18pt | 信息行过小、不便阅读 |
| 目录“目录” | 48–54pt | 左侧目录牌签只有小字 |
| 目录列表 | 26pt，编号24pt | 列表缩成中央小块 |
| 内容页章节 | 24pt蓝色加粗 | 与正文一样大 |
| 页内主题 | 18–20pt黑色加粗 | 长标题撞logo或换行压内容 |
| 分区标签 | 16–18pt蓝色 | 标题与解释没有层级 |
| 主要正文 | 16–18pt黑色 | 用过小字吸收过量内容 |
| 公式 | 按角色约18–24pt，Cambria Math | 数学符号被普通字体替换 |
| 表格/图内 | 表格12–15pt；图表坐标、图例≥12pt；页脚注释11pt | 缩略后关键信息无法阅读 |

字号与框宽必须同时考虑。相同字号在长标题和窄图注中不一定适用；调整框宽、断行和内容分区优先于继续缩小字体。

用户本次明确要求右上角厦大logo，当前示例及该参考模式使用原文件提取的真实资源，不以机构文字代替logo：

- 内容页：`assets/branding/xmu-energy-header.png`，包含厦门大学能源学院标识及中英文名称；参考位置x=10.214、y=0.152、宽2.829英寸，等比例插入。

学校标识的使用来自本次用户要求，不能推断新作者身份或把原稿姓名、导师、成果与研究数据带入新主题。

## 4. 主要内容区先分2–3区，再放子图

内容页可用区约x=0.5–13.0、y=1.45–6.6英寸，右上logo与蓝色页脚有独立区域。正文与证据共用这个区域，不能只占中间的一小部分。

“2–3区”是论证区域，不是图片数量。六图敏感性矩阵可以整体为一区，右侧规律解释为第二区。一区内部允许图、公式、短说明和局部标注形成紧凑组合。

常见分配（为参考归纳的起点，不是必须精确遵守的比例）：

- 背景页：正文论证约55%–65%，结构/案例/统计证据约35%–45%。
- 模型页：公式与模型约50%–65%，解释约20%–30%，辅助曲线约15%–25%。
- 结果页：主图组约65%–75%，右侧解释或底部结论约25%–35%。
- 算例页：对象/拓扑与实验说明约50%–60%，参数表及条件约40%–50%。

封面、目录、创新点、致谢允许较低密度；方法、算例、综述和结果页应体现原稿的中高密度。不是所有页面都要填满。

## 5. 什么是有效密度

提高密度靠增加必要的论证、模型、参数、图表和图文对应关系。大色块、空框、重复用途说明、装饰图片不会增加有效信息量。

制作前给每页标记：**核心判断 / 支撑内容 / 主视觉 / 辅助视觉**。正式内容应说明研究，而不是用“本页用途”“此处可插图”等说明替代研究叙事。

优先缩短重复句、合并图注、缩小无任务的留白和统一区域边缘。主区间隔约0.15–0.25英寸，区内图文约0.08–0.15英寸；紧凑表格和公式仍要检查实际渲染，不能靠颜色框掩盖截断。

当正文在图组旁只剩窄长栏导致术语碎裂、公式触碰横线、图例难读时，重新分配宽高或拆页；不将所有内容统一缩为小字。

## 6. 小图是辅助视觉，不默认独占一大块

原第9页小曲线解释阈值模型，第13页状态/结构图解释输入输出，第6页小图解释研究步骤，第29页小视觉辅助展望。共同规则是：小图紧贴它解释的内容，图注短，图形风格统一。

- 要说明一个关系：在该段文字/公式旁放一张小曲线或结构图。
- 要说明一个阶段：在技术路线模块内部嵌小图，而不是另开一页巨幅图框。
- 要比较结果：图组是主要证据，应占主要面积，与辅助小图区分。
- AI概念图：可帮助建立对象或机制印象，但不替代真实曲线、参数和实验结果。
- 预留图位：仅用于用户明确希望后续插入素材的草稿/模板模式；正式示例尽量填入原生示意或已有素材。

## 8. 渲染验收

检查封面和目录是否达到参考的视觉体量；右上logo是否清楚且等比；正文是不是黑色；红色是不是局部强调；是否有主信息和支撑证据；小图是否解释相邻内容；主要内容页是否仍像空模板。再检查表格、公式、图例和图注的实际可读性。

先看全页确认密度，再看局部确认清晰度。只检查“没有重叠”远远不够；没有溢出的空页面仍可能不符合参考。
