# 图片、示意图与 AI 文生图排版

## 先定义图片的用途

先判断主图还是辅助图。原稿的模型页与路线页经常把小曲线/结构图嵌在公式、文字或研究模块旁；不能默认给每张图一个大空框。密度与角色规则见 [layout-density.md](layout-density.md)。

逐页大纲增加“视觉素材”栏，写清图片承担什么论证任务、建议比例、实际来源和是否已有素材。根据内容选择研究对象照片、实物/装置图、方法示意、软件截图、论文原图、数据图或概念插画。不要每页都堆装饰图，也不要只用文字卡片替代研究可视化。

## 预留位置

| 页面模式 | 图位 | 建议用途 |
|---|---|---|
| 文左图右 | 右侧一张中图或两张小图 | 背景、研究对象、问题与证据 |
| 双图对照 | 两张等大图，分别配独立图注 | 前后状态、方法A/B、两个场景 |
| 三图横排 | 三张等大图和同层级图注 | 三种样本、三类问题、三个阶段 |
| 四图矩阵 | 2×2，同一比例与间距 | 多工况、四个变量、样本对照 |
| 大图详解 | 左侧约70%为主图，右侧要点 | 总体结构、系统边界、空间分析 |
| 流程配图 | 各阶段上方图位、下方说明 | 输入/过程/输出、实验操作 |
| 表格配图 | 左比较表，右对象/原理图 | 参数表、方法对比、实验设置 |

小图不能缩到图内文字无法阅读。简单场景可小图，复杂流程/论文多联图应占较大面积或拆页。图注13–14pt，图框与图注间隔0.1–0.15英寸，内容区与图位留出0.3英寸左右间距。

四图矩阵示例的图框为宽扁比例，适合宽幅结果图；复杂方形多联图应重新分配图框高度或拆页。流程配图存在明确先后依赖时，添加原生连接箭头，不能仅靠三列排列暗示因果关系。

草稿或版式库可以显式保留“预留图位”。正式成稿应插入实际素材，或在素材未提供时明确注明预留状态。未给 `file` 的图位会生成两层：一个可见的灰框加提示文字，上面再叠一个透明的原生图片占位符（名称为 `图片占位-<label>`）。在PowerPoint里点占位符就能插图；用脚本插图时，运行 `scripts/insert_image.py --slide N --label <label> --image x.png`，图片会按图位的原尺寸放置。不要用 python-pptx 的 `insert_picture`：这些页面没有对应的版式占位符，插进去的图片没有尺寸。不要把占位框和说明烘焙成一张底图。

## 输入格式

新增 `visual`、`gallery`、`image_method`、`table_image` 布局，示例见 `assets/style-demo-16.json`。每个图位支持：

```json
{
  "label": "研究对象示意",
  "caption": "图1 研究对象与系统边界",
  "file": "images/object.png",
  "fit": "contain",
  "annotations": [{"text": "研究对象", "x": 0.1, "y": 0.15}]
}
```

`file` 省略时生成原生图片占位符；相对路径相对于内容JSON。`contain` 保留全图，适合论文图、截图与示意图；`cover` 用PPT原生裁切填满框，适合照片，不拉伸图片。`annotations` 为独立可编辑文字，坐标是相对图位左上角的0–1比例。

图片本身不能因此变为可编辑矢量；图框、图注、编号、箭头和强调文字应独立生成原生对象。科学数据图优先使用真实数据生成原生图表。

## 图与框贴合

`fit: contain`（默认）时，脚本按图片的原始比例收缩图位：细边框画在图片的实际边界上，图注紧贴在图片下方，图片和图注作为一组在分配区域内垂直居中（`valign: top` 改为顶部对齐）。不会出现灰色留边，也不会出现图框比图片大的情况。照片需要填满固定比例的框时，用 `fit: cover`（原生居中裁切）。

## 论文原图（paper_figure）

做论文汇报时，优先用论文原图，保持原配色，不重绘、不重新上色。每个支撑论点的子图都要放，放不下就拆页，不删子图，也不做缩略图拼贴。

```json
{"type": "paper_figure", "file": "figs/fig3.png", "crop": [0, 0, 0.5, 0.48], "tag": "(a)",
 "caption": "图3a 各城市顶层与底层不舒适时长差"}
```

- `crop` 依次是左、上、右、下四边被裁掉的比例（相对原图），用的是PPT原生裁切：原图文件不变，在PPT里可以拖动恢复。用它从论文组图里取出单个子图。
- 默认 `fit: contain`，不加灰色图框。图里的文字没法编辑；子图编号和图注由PPT原生文本添加。
- 论文原图里坐标字号太小（投影时 <12pt）的，宁可加大图位或拆页，也不要缩小。实在看不清的，请用户提供源图或源数据重新出图，不要擅自重绘。

## AI 文生图

选图优先级、去“AI味”的提示词和生成后自查，统一以 [visuals.md](visuals.md) 为准。这里只补充操作要求：
- 按图位比例逐张生成素材，不要生成整页幻灯片；标题、编号、标签和箭头都用PPT原生对象添加。
- 生成的文件存到 `images/`，提示词存到 `images/<名称>.prompt.md`，图注写“AI生成示意”。
- 没有图像生成工具时，保留提示词和预留图位，并告诉用户；不要声称已经生成，也不要转去调用需要凭证的接口。
