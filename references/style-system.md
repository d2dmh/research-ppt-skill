# 从参考答辩PPT提炼的跨主题视觉系统

目标是迁移排版和视觉语言。用户后续换成医学、建筑、计算机、社会科学或其他主题时，内容结构来自新材料，版式以本系统为基线。

用户已进一步指定蓝黑红三色文字、厦大标识与中高密度科研排版；具体规则与类型覆盖以 [layout-density.md](layout-density.md) 为准。16页图位库是草稿排列示例，不是正式汇报密度基准。

## 可保留的设计参数

| 项目 | 基线 | 使用边界 |
|---|---|---|
| 画幅 | 16:9，13⅓×7.5英寸 | 跟随用户指定画幅 |
| 背景 | 白色 | 内容分区统一灰底 |
| 主蓝 | #1D50A2 | 章节、标题、页脚、图表主系列 |
| 深蓝 | #17347D | 次级编号与结构 |
| 正文 | #000000 | 黑色正文与图注 |
| 强调 | #C00000 | 少量关键词或关键数值 |
| 分区 | #F2F2F2（参考稿 bg1 lumMod 95%） | 所有内容分区统一灰底，用户确认的规则 |
| 页底结论条 | #FCEBDD | 只用于页底一句结论，不堆满整段红字 |
| 中文 | 微软雅黑，显式设置East Asian字体 | 不依赖不明确的主题继承 |
| 西文/数字 | Arial | 正文缩写、单位、日期统一；数学公式使用Cambria Math |
| 封面题目 | 约40pt，必要时分两行 | 保持原稿视觉体量与安全边距 |
| 目录 | 牌签48–54pt，列表26pt | 不缩成中央小字块 |
| 章节标题 | 24pt，加粗 | 左上固定层级 |
| 页内标题 | 18–20pt，加粗 | 带编号或结论性标题 |
| 正文 | 16–18pt | 紧凑标签可14pt，不能用缩小正文吸收过量内容 |
| 图例/坐标 | ≥12pt，清晰无衬线 | 页脚注释11pt；更小的字在投影时看不清，不继承原图小字 |

参考的细蓝横线、左上圆底章节数字标牌、右上机构标识与蓝色页脚可保留。这些是同风格的重要识别特征，不要套用与参考无关的通用模板规定将其删除。

## 版式选择与主题迁移

- **封面**：上方居中竖向徽章，中部蓝色大题目，下方署名。本次用户指定沿用厦大标识；当前参考模式使用提取的校徽与右上能源学院logo，用户指定其他机构时替换。
- **目录/过渡**：左侧竖向蓝色“目录 / CONTENTS”，右侧圆圈编号章节。章节数量和名称随新研究确定，可突出当前章节。
- **背景/问题**：左侧两块动机与问题，右侧证据图或目标，底部归纳。替换成新领域的图片和证据。
- **研究现状/比较**：定义与范围区配分类表或对比矩阵，用结论框点出研究空缺。
- **技术路线**：按新方法的阶段与输入输出组织流程图，搭配各阶段说明，全部使用原生形状和文字。无需强制三步。
- **模型/方法**：左原理右流程、或三栏比较；公式使用数学字体，正文解释保持中文/西文字体体系。
- **结果**：优先双图、2×2或2×3矩阵加右侧解释；同一指标保持颜色和坐标一致，图下结论解释证据。
- **结论**：三条编号浅灰结论卡片是参考的可复用形式；每条用短标题加说明，数量随研究内容变化。
- **展望**：两到三个方向，用可编辑图标或图形配说明。避免给无关研究强加储能或可再生能源展望。

混合使用版式，以内容类型决定页面；不能所有页面套同一个双栏。保留参考的学术密度，但较长论证拆页或重新划区，优先让图与重点可读。

## 迁移时要清除的原稿信息

原研究题目、姓名、导师、日期、成果、模型名、数据、百分比、图表和文献不迁移。学校标识按用户当前明确要求保留/替换，不据此推断身份。需要新增证据时检索并注明出处，不编造研究结果。

参考有字体混用、SmartArt文字重叠和公式贴线的问题。风格学习不复制这些缺陷，也不能以“跟原图像素相同”为新主题PPT的合格标准。

## 可执行起点

正式汇报用 `scripts/dense_deck.py`：优先用版式模板（[layouts.md](layouts.md)，示例 `assets/layout-demo.json`），需要精确控制时用绝对坐标 blocks（`assets/density-demo.json`）。`scripts/styled_deck.py` 加 `assets/style-demo-16.json` 只是预留图位的草稿工具。图位规则与AI配图流程见 [figure-layouts.md](figure-layouts.md)。

这是起点，不是排版上限。新主题需要文献矩阵、真实图片、模型公式、地图、操作步骤等内容时，按本视觉参数创建相应页面，不强行改写成有限的基础布局。示例内的三阶段/三结论/双图只是具体布局的容量，整份PPT不固定为六页、16页或31页。
